# P5 · 地图改版计划

> 2026-10-12 · 只覆盖网页版。**本文只是规划,还没有改任何代码。**
> 依据:三份代码盘点(完整 Map 页 / 所有其他用到地图的组件 / Marginalia 地图交互),加上 owner 的要求:
> 要 Marginalia 那种**椭圆形、可左右旋转的世界地图**(不是 3D 球),但**不要硬搬**,要从功能出发,结合现有 Map 页和其他地图组件,看怎么嵌入更合理。

---

## 0. 一页结论

1. **地图要承担两件不同的事,现在混在一起了。**
   - **足迹(World):** 我去过哪些国家、哪些城市、去了几次、待了多久。这是 Marginalia 那种椭圆世界图适合做的事。
   - **路线(Route):** 这一趟旅行怎么走的、怎么回放。这是现有 Mercator 页面在做的事。
   - 现有页面用一个「本次 / 全部」开关硬塞两件事,「全部」模式里连续的几趟旅行被画成**同一条线**,趟与趟之间会多出一条不存在的飞线。这是现在最弱的一块。
2. **方案:** 地图页默认是**椭圆世界(足迹)**,点国家进入国家详情,点某一趟旅行进入**原来的路线视图**。路线视图保留,只修 bug,不重写。
3. **世界视图用全新的模块写**(`src/views/map/world/`),不往 1770 行的 `map.ts` 里堆。路线视图稍后再拆。
4. **先做地基(P5.0)再做功能。** 盘点发现了几个会直接影响新功能的老问题:换主题地图不刷新、国家名到 ISO 的映射有 3 套、「去过」不看日期、坐标来源 4 种、地图 CDN 离线不可用、换行程/范围后 Replay 会触发多次。这些不修,新地图一上来就带着这些问题。
5. **和已做的东西打通:** 护照印章(国家入境章/城市章)、行李秤无关,但印章、日记封面、花费、Guide 收藏、Nomad 地点都能进国家详情面板。

## 1. 现状盘点(要点)

### 1.1 用到地图的地方一共 8 处

| 位置 | 技术 | 看什么 | 坐标来源 |
|---|---|---|---|
| **Map 页** `views/map/map.ts`(1770 行) | amCharts5(CDN)Mercator | 国家点亮、路线、编号图钉、飞线、小人 + 飞机、省份下钻、时间轴、5 个图层 | `leg.lat/lng` → 内置城市表 → localStorage 缓存 → Nominatim(1.1 秒一个,串行) |
| Dashboard「整个旅程」`dashboard-map.ts` | amCharts Mercator,不可交互 | 国家着色 + 状态图钉 | 只用内置城市表,**忽略** `leg.lat/lng` |
| Dashboard「这一天」`dashboard-daymap.ts` | Leaflet | 当晚住宿 + 当天计划点 | 同步解析器 + geocode |
| Itinerary 计划地图 | Leaflet | 每天一条虚线 + 箭头 + D1/D2 | `PlanItem.lat/lng`(会回写) |
| Guide 步行地图 | Leaflet | 编号图钉 + 金色折线 | `Waypoint.lat/lng`(会回写) |
| Journal 地图页签 | Leaflet | 每城日记数 | 只用内置城市表,**查不到的城市静默丢掉** |
| `landing-map.ts` | amCharts | (无人引用) | **死代码** |
| Nomad 详情 | Google 地图 iframe | 一个地点 | 不存坐标 |

街道级的(日地图、计划地图、步行地图、日记城市图)**必须保持 Leaflet**,和这次世界图无关。

### 1.2 Map 页现有结构(要保留的 vs 要修的)

- **保留:** 路线(带弧度的虚线)、编号图钉、小人和飞机叠层、Replay、省份下钻(约 105 个国家)、导出、5 个图层(nomad / journal / guide / stay / expenses)。
- **修:**
  - 换主题后图表不刷新(`initMap` 被 `_initialized` 拦住)。
  - `bootChart` 里每次重建都再给按钮挂一遍监听器,切几次范围后 Replay 会触发 N 次。
  - `_lit`、`_drillSeries` 等模块级变量在 `teardownChart` 里不清,切换后残留。
  - 「减少动态效果」检查是死代码(`replay=false` 从来没传过),飞线、小人、点亮动画都不遵守。
  - 「去过」不看日期,未来的行程也点亮国家。
  - 地理编码失败的站点静默丢掉,用户不知道少了哪些。
  - 所有文案写死英文(只有导出面板走了 `t()`)。
  - `amcharts-loader` 会把加载失败缓存成 rejection,一次失败要重启页面才能重试。
  - 没有任何人用 `navigateTo('map', …)`,地图页**读不了** `NavIntent`,所以没有「在地图上看这一站」这种深链。
  - 每帧对所有 DOM 叠层(区域标签、国家钉、图层钉)做 `chart.convert` 和 `getBoundingClientRect`,下钻大国(美、俄、中)会有几十个标签,会卡。

### 1.3 重复和不一致(应合并)

| 问题 | 位置 |
|---|---|
| 国家名 → ISO **三套** | `map/geo.ts:28`(主表)、`data/stamps.ts:31`(我写的,语义不同)、`dashboard-map.ts:83`(再加子串匹配) |
| 欧洲中心点 **4 个值** | `geo.ts:130` {6,48}、`dashboard-map.ts:16` {15,54}、`landing-map.ts:37` {6,47}、Leaflet 里还有 3 个 |
| 坐标查找 **4 种路径** | Map 页走 geocode(含缓存和网络);Dashboard 缩略图、日记、行程只走内置表;`leg.lat/lng` 是最便宜的来源,但多处忽略 |
| 国家颜色 **3 套** | `map-shared.ts` 里 9 个欧洲国家写死;`country-ink.ts` 一套;行程色(`coverColor`)一套 |
| amCharts 启动代码重复 3 份 | `map.ts`、`dashboard-map.ts`、`landing-map.ts` |
| Leaflet 启动代码重复 4 份 | 同一个瓦片 URL、归属文字、虚线样式 |
| geocode 缓存 key 只用小写城市名 | `countryHint` 不在 key 里,同名城市(两个 Bern)会撞 |

### 1.4 离线与性能

- amCharts 核心和 geodata 都从 CDN 加载,**Service Worker 没有任何缓存规则**。离线时地图整页不可用。
- 地图代码本身不大(`map-*.js` 约 39KB),Leaflet 约 149KB 且已拆成独立 chunk。Dashboard 静态引入了地图 loader,会进入入口包(236KB)。

## 2. 从 Marginalia 学什么、不学什么

Marginalia 的地图**不是球**,是 amCharts5 的 `geoNaturalEarth1`(椭圆世界)加 `panX: 'rotateX'`:左右拖动时经度旋转,世界首尾相接,上下拖动只是平移。三维球体只用在角落的装饰小地球和进场动画上,和这件事无关。

| 做法 | 决定 | 原因 |
|---|---|---|
| `naturalEarth1` + `panX: 'rotateX'` | **采用** | 这正是 owner 要的交互,On the Road 的 amCharts 版本也支持 |
| 点国家:先把旋转归零、切成 Mercator、再放大到该国 | **采用** | 避免残留旋转让 Mercator 画面歪掉;这是 Marginalia 踩出来的 |
| `zoomToDataItem` 后再退到 fitted × 0.62 | **采用** | 放大后保留邻国可见,有地理语境 |
| 其他国家压暗,只留选中国 | **采用** | 清楚的焦点状态 |
| 原地改填色、不重建系列 | **采用** | 切换图层/模式不闪 |
| 面板打开时图表宽度用 CSS 过渡收缩 | **采用**,但改成容器宽度 | 平滑 |
| DOM 悬停卡片 | **采用**(仅桌面) | 比 amCharts 自带 tooltip 好控制样式 |
| 叠几个 `setTimeout` 重试(80/640ms、20/200/520ms)等布局稳定 | **不采用** | 从不取消、会叠;换成「一个带取消令牌的过渡」,用 amCharts 动画结束事件而不是定时器 |
| 无惯性、无范围限制、竖向不旋转 | **改进** | 加平移范围限制,可选惯性 |
| 无背景/海洋 | **改进** | 加弱经纬网和一个纸感底,让椭圆有「图」的感觉 |
| 小国难点 | **改进** | 加城市点和扩大点击区域 |
| 深色专属、读书主题的拍立得卡片、打字机、五页签面板 | **不采用** | 与旅行无关,用 On the Road 的 token 重做 |
| 大陆依次飞入的进场动画 | **可选(P5.4)** | 可复用,但不是必须 |

## 3. 目标设计

### 3.1 信息架构

```
Map 页
 ├─ World(足迹,默认)  ← 新:椭圆、可旋转、所有行程
 │     └─ 点国家 → Country(同一张图,Mercator 放大 + 国家详情面板)
 │              └─ 点某一趟 / 「查看路线」→ Route
 └─ Route(路线)      ← 现有页面,修 bug,保留 Replay / 小人 / 图层
        └─ 「← 世界」回到 World
```

- 顶部用一个**分段控件「世界 | 路线」**,取代现在的「本次 / 全部」开关。「全部」的内容并进 World。
- 默认进入哪里:见 §8 Q1。我的建议是**总是进 World**,当前这一趟高亮,并放一个醒目的「打开当前路线」按钮。

### 3.2 World 视图

**画面**
- 椭圆世界,左右拖动旋转(`rotateX`),上下拖动平移,滚轮/双指缩放。缩放范围限制在 1–8,平移范围限制,不会拖丢。
- 进入时把画面转到**最近或当前一趟的中心经度**,不是固定欧洲。
- 底:纸感背景(沿用纸质组件库的 `--paper-grain`),椭圆外轮廓 + 很淡的经纬网(每 15°),不是纯黑底。
- 陆地:没去过 = 暖灰纸色;去过 = 琥珀色阶(哑光),按**到访次数**加深;**计划中**(行程日期在未来)= 同色的虚线描边 + 很淡的填充,**不**算去过。可切换为「按行程着色」。
- 国家边界用 `--rule`,深浅两套都跟主题。

**图层**
- 每趟旅行一条**大圆弧线**(`MapLineSeries`,沿地球曲线),颜色取该行程的 `coverColor`。**不同旅行之间不再连线**,修掉现在的假飞线。可开关。
- 城市点:一个小圆点,当前所在城市用小人(`am5.Picture` 气泡,**不再用每帧同步的 DOM**)。
- 小国/港澳/梵蒂冈等:点击区域加大(透明的大圆点击层)。
- 国家标签:只给去过的国家、缩放 ≥ 2 时显示,总数封顶。

**交互**
- 悬停(桌面):DOM 卡片「🇩🇰 Denmark · 2 次 · 27 晚」。
- 点击/轻点国家 → 进入 Country 状态(见 3.3)。
- 点击行程芯片 → 只显示该趟的线和点;再点「查看路线」→ Route。
- 键盘:Tab 在侧栏列表里切换,Enter 进入国家(地图本身是图形,面板列表是可访问的等价入口)。
- 减少动态效果:不做自动旋转、不做惯性、进入国家直接跳转无动画。

**面板(桌面右侧 340px,手机底部半屏)**
- **总览:** 国家数、城市数、晚数、总里程、大洲数(复用 `map-stats.ts` 的 `summarizeRoute` 与 `buildCountryStops`);行程列表(色块 + 名称 + 日期),点击进入筛选;护照卡「🛂 17 枚印章」→ 打开护照本。
- **没能定位的站点:** 如果有站点地理编码失败,面板底部列出来(现在是静默丢掉),可点击「去行程里补坐标」。

### 3.3 Country 状态(点国家之后)

照 Marginalia 的做法在同一张图里切投影,但用可取消的过渡:

1. 取消正在进行的过渡 → 旋转归零 → 投影切 Mercator → 拖动改为平移 → 放大到该国(再退到 0.62)→ 其他国家压暗。全程**一个过渡令牌**,点别的国家会取消上一个。
2. 省份下钻沿用现有 `drillCountry`(约 105 个国家),只画轮廓,不额外加东西。
3. 面板变成**国家详情:**

| 区块 | 内容 | 数据 |
|---|---|---|
| 抬头 | 旗、国名、总晚数、到访次数 | `legs` |
| 印章 | 该国的入境章 + 各城市章(`paperStamp` 小贴纸,点击打开护照本并定位) | `stampsFor(legs, today)` 按 iso 过滤 |
| 去过的行程 | 每趟:行程名、日期、城市、晚数,点击 →「查看路线」 | `legs` + 行程 |
| 日记 | 篇数 + 前 3 张封面(点击跳 Journal 并按城市筛选) | `journalStore.subscribeAll` + `dashboard/journal-places.ts` 的 `buildPlaceGroups` |
| 花费 | 每趟的花费(用各自的币种),只有币种一致时才给合计 | 需要跨行程的 `expenseStore`(见 §5) |
| Nomad / Guide | 收藏的地点数、攻略条数 | `nomadStore`、`cityStore` |
| 操作 | 打开 Guide、打开 Journal(已筛选)、返回世界 | `navigateTo` |

### 3.4 Route 视图(现有页面)

- 外观与功能保持:路线弧、编号图钉、小人 + 飞机、Replay、5 个图层、导出、省份下钻。
- 去掉「本次 / 全部」开关(并进 World)。**时间轴拖动条**目前只在「全部」里出现:先不动,放进 P5.4 作为 World 的「回放所有旅程」。
- 修 §1.2 里的全部 bug(P5.0)。
- 入口:从 World 的行程芯片、国家面板的「查看路线」,或 Dashboard「整个旅程」地图点击进入。
- 左上角「← 世界」。

### 3.5 Dashboard 里的地图

- 「整个旅程」缩略图继续用 amCharts Mercator(不可交互),但改为:**共享上色模块**(与 World 同一套 `countryColor` / 主题监听)、**优先用 `leg.lat/lng`**(不再只用内置表)、点击进入 Map 页并带 `NavIntent`(进入当前行程的 Route 或 World)。它的 loader 改成懒加载,不再进入入口包。
- 「这一天」继续用 Leaflet,不动。

### 3.6 和护照印章的联动

- **面板里:** 总览有护照卡,国家详情有该国印章。
- **到达新国家时(P5.4):** 打开地图,如果有**还没看过**的国家入境章(`stamp-seen`),画面自动转到那个国家,国家点亮,同时盖一次章的动画。这是「到一个新国家 = 一个小仪式」的地方。
- **不在地图上直接画印章。** 印章是纸质物件,放进面板和护照本里;地图上只用点和颜色,保持干净。

### 3.7 响应式

- 桌面:图表 + 右侧 340px 面板;面板打开时图表宽度过渡收缩(按**容器宽度**,不按视口)。
- 平板(≤ 980px):面板收窄到 280px。
- 手机(≤ 680px):图表占满屏幕高度(`100dvh` 减顶栏,避免页面滚动和图表拖动抢手势);面板变**底部半屏**,可上拉到全屏;缩放按钮和城市点的点击区域 ≥ 44px;没有悬停卡片,改为点击选中。
- Marginalia 的两个断点(CSS 900 / JS 980)不一致,这里统一用一个常量。

## 4. 技术方案

### 4.1 新增和改动的模块

```
src/views/map/
  world/                      ← 新,P5.1 起
    world-model.ts            纯函数:legs + trips + today → 国家/城市/行程线/汇总(带测试)
    country-model.ts          纯函数:国家详情所需数据(印章、行程、日记、花费、计数)(带测试)
    world-view.ts             amCharts 世界图:椭圆、旋转、着色、线、点
    world-state.ts            状态机 world → country → route,一个可取消的过渡
    world-panel.ts            总览面板 + 国家面板(手机底部半屏)
    world.css
  map.ts                      路线视图(P5.0 只修 bug,不重写)
src/data/geo-index.ts         新,合并国家名→ISO、城市→坐标、洲、欧洲中心常量
src/views/map/amcharts-boot.ts 新,共享的 Root / 主题 / 重试加载 / 类型
src/views/map/map-theme.ts    新,监听 otr:theme-change 并通知所有地图重新上色
```

### 4.2 坐标:一个来源,一个优先级

`geo-index.cityCoords(city, countryHint)`:
1. `leg.lat/lng`(已持久化,最便宜)→ 2. 内置 `WORLD_CITIES` → 3. localStorage 缓存(**key 加上 countryHint**)→ 4. Nominatim(串行队列,保留)。
- Dashboard 缩略图、日记地图、世界视图都走它,不再各自查。
- 地理编码失败的结果要**返回出来**(现在是静默丢掉),交给面板列出。

### 4.3 amCharts 启动与主题

- `amcharts-boot.ts`:`createChart(container, { projection, theme })`,统一类型,加载失败**可重试**(不缓存 rejection)。
- `map-theme.ts`:地图读颜色的唯一入口;监听 `otr:theme-change`,对已存在的图表**原地重新给多边形和线上色**,不重建(Marginalia 的做法)。Map 页、Dashboard 缩略图、World 都接它。
- Leaflet 的重复启动(4 份)抽成 `leaflet-boot.ts` 放到 P5.5(可选),不阻塞。

### 4.4 离线

- Service Worker 给 `cdn.amcharts.com` 加一条 `CacheFirst` 运行时缓存(30 天),地图打开过一次之后离线可用。**不把 amCharts 打进包**(几 MB)。
- 世界图用的 `worldLow` 已被缓存规则覆盖;各国省份文件按需访问时同样被缓存。

### 4.5 数据需求

| 需求 | 现状 | 做法 |
|---|---|---|
| 所有行程的站点 | `routeStore.subscribeAll` 已有 | 直接用 |
| 日记按国家/城市计数 | `journalStore.subscribeAll` 已有,但 `destination` 是自由文本,没有国家字段 | 用「匹配到的站点 → iso」+ 已有的 `buildPlaceGroups`;匹配不到的归入「其他」 |
| 跨行程花费 | `expenseStore` 只能按行程订阅 | **给 `expenseStore` 加 `subscribeAll`**(和 route/journal 同样的 tagged-collection 方式),面板按行程分别显示各自币种;只有币种一致才给合计 |
| 行程颜色 | 在 trip 上(`coverColor`),leg 上没有 | 世界模型里按 `tripId` 关联,不改 leg 的 schema |
| Nomad / Guide 坐标 | 不存坐标 | 世界视图**不画**这两个图层的点,只在国家面板里给数量;图层仍留在 Route 视图 |

**不改 Firestore schema。** `leg.lat/lng` 已经是 schema 里的字段。

### 4.6 状态机(替代 Marginalia 的定时器堆)

```
world ──点国家──▶ focusing ──动画结束──▶ country ──点行程/查看路线──▶ route
  ▲                  │取消                    │
  └──────返回────────┴────────返回────────────┘
```
- 每次过渡产生一个 `token`;新的过渡先让旧的作废。
- 用 amCharts 动画对象的 `waitForStop()` / 事件等待缩放结束,**不用**固定毫秒的 `setTimeout`。
- 过渡中禁用重复点击;`dispose` 时取消所有未完成的过渡。

### 4.7 性能

- 世界视图的城市点、行程线、小人都用 amCharts 系列(`MapPointSeries`、`MapLineSeries`、Picture 气泡),**不用每帧同步的 DOM 叠层**。DOM 只留标签(≤ 20 个)和悬停卡片。
- 世界图只有 4 个系列(陆地、线、点、当前位置)。
- 地理编码保持串行,但**先渲染已有坐标的部分**,再补;面板显示「还有 N 个站点在定位」。

### 4.8 深链

## 6. 风险

| 风险 | 说明 | 对策 |
|---|---|---|
| naturalEarth 下 `chart.convert` 的叠层位置 | 旋转时靠近变更线的点会跳边 | 世界视图不用 DOM 叠层,用 amCharts 点系列;标签只在静止时更新 |
| 投影切换时的画面跳动 | Marginalia 用 3 次定时器兜底 | 用单一过渡 + 动画结束事件;预览里专门测来回切换 20 次 |
| 地理编码慢(1.1 秒/个) | 新用户第一次打开会慢 | 先画已有坐标,后台补;优先用 `leg.lat/lng` |
| Marginalia 的 `rotateX` 行为我没在 On the Road 里实测 | 两边 amCharts 版本可能不同(CDN 与 npm) | P5.1 第一件事是做一个只含旋转的最小原型,确认后再继续 |
| 重构 `map.ts` 的回归 | 1770 行、约 30 个模块级变量、测试几乎没有 | P5.0 只修明确的 bug 并补测试;大拆分不在 P5 范围 |
| 跨行程花费币种不一致 | 不能直接相加 | 分行程各自币种显示,币种一致才合计 |
| CDN 离线 | amCharts 不在包里 | Service Worker 运行时缓存;首次离线打开仍不可用(要说明) |
