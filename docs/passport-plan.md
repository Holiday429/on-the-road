## 0. 定位（已确认）

两套印章，分工不同：

| | **卡片邮戳**（Itinerary） | **护照国家章**（全站） |
|---|---|---|
| 范围 | 当前行程的每个城市 | 用户的**所有**行程，跨行程长期累积 |
| 粒度 | 每城 2 个：到达章、离开章 | 每个国家 1 个章（同一国家重访见 Q1） |
| 出现方式 | 按时间节点**自动**出现 | 到达新国家后由用户**亲手盖**（仪式），也可一键自动 |
| 作用 | 行程状态：到了 / 走了 | 收集 + 回顾，与 Map 足迹打通，吸引长期使用 |
| 入口 | 卡片本身 | 头像（sidebar）、Dashboard、Itinerary、Map、Profile |

护照是**全站顶层功能**，不属于任何一次行程：一人一本，封面写的是用户，不是行程名。

## 1. Itinerary 卡片邮戳（P7.0）

### 1.1 规则
- **到达章**：`dateFrom <= today` 时出现。圆形邮戳：城市名（环字）+ `ARR` + 日期 + 到达方式（AIR / RAIL / COACH / SEA）。
- **离开章**：`dateTo <= today` 时出现（离开当天）。矩形/椭圆邮戳：`DEP` + 日期 + 晚数。比到达章小约 15%，与到达章错开约 30% 叠压，角度不同。
- 两个章的墨色都使用该国家的墨色；形状由城市名决定，同一个城市永远长同一个样子。
- `today` 沿用 `todayIso()`，因此 Dashboard 的时间旅行时钟也能回放章的出现过程。
- 位置：卡片 body 右上**日期块的左侧**，到达章压住日期块左缘。桌面 60px / 52px；≤640px 时移到标题行右侧，为 46px / 40px。
- **透明背景**：去掉 `.pp-sticker` 的纸片底、阴影和 blur，只留墨迹（亮色模式用 `multiply`，暗色模式沿用现有提亮规则）。
- 首次看到时播放一次落章动画（沿用 seen 记录），之后静态显示。
- 点击 → 打开全局护照，并翻到该国家的章。

### 1.2 顺带修改
- **删除过往城市照片的去饱和效果**（`timeline.css:144` `.route-leg.status-past .route-leg-cover-img { filter: saturate(.55) }`）。照片保持原色，过往状态完全交给邮戳和时间线圆点表达。
- 详情页 hero：删除照片上的纸片贴纸，改为在 hero 日期行旁放这两个邮戳，用浅色墨（奶白 + `screen` 混合）保证在深色遮罩上清晰可读。
- 时间线圆点：已结束 = 实心国家墨色，当前 = 呼吸光圈，未来 = 空心。
- 顶部 strip → 改为全局护照入口，见 §5。

## 2. 护照国家章（视觉 v2，P7.2）

“不用太复杂”：每个国家一个章，但**国家之间要明显不一样**（参考图 3）。

### 2.1 一个章由 4 个维度组成，全部由数据确定

| 维度 | 设计 |
|---|---|
| 外框 | 约 10 种：圆、双圈、圆角矩形、斜置方框、切角矩形、拱顶、椭圆、六边形、邮票锯齿边、三角旗；按国家种子选取 |
| 中心图形 | 国家地标线稿（DK 小美人鱼、DE 勃兰登堡门、NL 风车、BE 原子塔、FR 铁塔、ES 圣家堂、PT 贝伦塔、CH 雪山、IT 斗兽场…）。已去过的国家逐个手绘，其余用 Tabler Icons（MIT）按大洲或通用图形兜底 |
| 文案 | 国家名 + 一句按该国停留晚数生成的话：`DAY TRIP TO` / `WEEKEND IN` / `A WEEK IN` / `N NIGHTS IN` + 入境日期 + 年份 |
| 墨迹 | 国家墨色（已是哑光色）+ 磨损滤镜 + 按盖章力度变化的深浅；用户亲手盖的章，墨色深浅来自按压时长 |

另加一款窄体展示字体（候选 Oswald / Big Shoulders），只用于印章里的国家名。

### 2.2 只保留这几类
- **国家章**（主体）。
- **行程完成章**：可选，每次行程结束后盖在该行程最后一个国家章旁边的小章，写着 `TRIP · 74 DAYS`。是否需要见 Q4。
- 不做出境/入境配对，不做申根章，不做里程碑章（v1 的这些设计全部取消）。

## 3. 护照本体（全屏，P7.3）

### 3.1 容器
- 全局路由 `#passport`，可带深链：`#passport?country=DE` 打开到该国的章，`#passport/visas` 打开签证页。路由不依赖当前行程。
- 全屏沉浸：桌面纹理背景，护照居中；桌面端左右两页同时展开，≤768px 单页滑动。

### 3.2 结构
```
封面   深色布纹 + 烫金徽章 + PASSPORT · 护照 + 昵称
资料页 照片 · 昵称 · 国籍 · 签名 · 统计（N 国 · N 城 · N 晚 · N 次旅行）· MRZ 码
签证页 用户填写的签证（可选，见 §4）
印章页 按时间顺序排列的国家章；每次行程开头有一条细横幅“2026 · Euro Trip”作为分隔
       侧边索引标签：按年份或按行程
下一站 计划中的国家（与 Map 的虚线规则一致）显示为虚线占位：“Portugal · 还有 12 天”
封底   空页数 / 累计进度，以及“在地图上看足迹 →”
```

### 3.3 资料页（不要求真实信息）
- 默认只有：**昵称**（必填，默认用 displayName）、照片（默认 Google 头像，可上传）、国籍（与 Safety 的 nationality 共用）、签名（手写板，可跳过）、“职业”趣味字段（默认 TRAVELLER）。
- **可选的“证件信息”**：放在资料页背面，用户主动展开才填。字段包括：真实姓名、护照号、签发国、签发日期、有效期、出生日期。
  - 填了之后可以当作真实护照来查：一键复制（订票填表用）、默认打码、点击显示。
  - **有效期提醒**：护照有效期距离任何一次计划行程的结束日少于 6 个月时，在资料页和 Dashboard 提醒。
  - 隐私：仅本人可读写（Firestore rules）；不进入分享图、导出、AI 请求、协作者可见范围。
  - 不强制、不引导必填。

### 3.4 印章页排版
- 每页 4–6 个章，散落排布：由确定性种子 + 碰撞回避决定，允许少量叠压。用户亲手盖的章用用户选的落点。
- 背景：防伪底纹（SVG guilloche）+ 纸纹 + 页码。
- 页码规则：**已盖的章页码固定**（存储），新章只往后面的空位放；行程编辑不会导致已盖的章“跳页”。

### 3.5 翻页
- 自写 CSS 3D：拖动页角时页面跟随手指 `rotateY`，松手后回弹或完成翻页，带阴影渐变；点击页边、键盘 ←/→、侧边索引也能翻。
- 只渲染当前两页 ±1；翻页过程中印章临时去掉滤镜（应对 Safari 掉帧）。

### 3.6 音效（默认开启）
- 翻页沙沙声、盖章“咚”、封面开合声，都是很短的音频（总共 <60KB）。
- 工具栏有静音开关，选择会记住（per-device）。`prefers-reduced-motion` 只影响动画，不影响声音。

## 4. 签证页（可选，P7.6）

- 面向**所有国家/地区**的签证，不只是申根。一张签证 = 一页贴纸式样（visa vignette），颜色取签发国的墨色。
- 字段：签发国/地区（包含 “Schengen Area” 这类区域选项）、签证类型、号码、有效期起止、入境次数（单次 / 两次 / 多次）、每次可停留天数、备注；签证照片可选上传。
- 与足迹打通：
  - 自动关联“在有效期内去过/将去的行程与国家”，签证页底部显示“用于：Euro Trip 2026（DK DE NL …）”。
  - 计划中的行程若在签证过期后才离开该国/区域 → 提醒。
  - Schengen 类签证额外显示 **90/180 天已用天数**（从行程推导），这是很实用的功能。
- **不内置“哪些国家需要签证”的数据库**：政策随国籍和时间变化，容易过期出错。只在计划中的国家旁放一个“添加签证”的轻入口，是否需要由用户判断。
- 隐私规则同 §3.3。

## 6. 参与与回顾（P7.4 / P7.5）

### 6.1 盖章仪式（国家章）
触发：进入一个新国家（或重访，见 Q1）的到达日已到，且这个章还没盖。
1. 入口红点（头像 / Dashboard / Itinerary）→ 打开护照，自动翻到空位。
2. 底部出现木柄橡皮章 → 拖到页面任意位置 → **按住**（越久墨越深，带“最佳区间”提示圈）→ **松开**落章：音效 + 纸面轻震 + 墨点；移动端会震动。
3. 存储落点、角度、力度、时间；以后每次打开，章都在原来的位置。
4. “自动盖章”按钮：使用默认位置，只播一次动画。键盘 Enter 等同于自动盖章。

### 6.2 首次打开：补盖历史足迹
第一次打开时，护照是空的 → “你已经去过 9 个国家” → 可以一个个亲手补盖，也可以“一键全部盖上”（快速连盖动画）。旧的 `otr:stampsSeen` 记录不再使用。

### 6.3 章的背面 = 国家回忆卡
点一个章 → 章揭起放大并翻转，背面显示：这个国家去过的城市、总晚数、每次行程的日期、日记篇数 + 照片缩略图、每次行程在该国的花费（各自币种，不跨币种合计，沿用 P5 Q4 规则）。数据直接复用 `country-model`。
动作：在地图上看 / 打开该次行程 / 看日记。

### 6.4 回放
封面“重温”：按时间自动翻页，按用户当时的落点和力度逐个重新落章，配音效；结束后可跳转 Map 的“Replay all trips”。

## 7. 数据与架构

### 7.1 存储（全部按用户，不按行程；协作行程下每人各有一本）
| 路径 | 内容 |
|---|---|
| `users/{uid}/passport/me` | `profile { nickname, photoURL, nationality, occupation, signature }` · `placements { [stampId]: { page, x, y, rot, pressure, at } }` · `prefs { sound }` |
| `users/{uid}/passport/document` | 可选证件信息（单独文档，便于单独加规则、单独排除在导出外） |
| `users/{uid}/visas/{id}` | 签证 |

- `stampId = country:{iso}` 或 `country:{iso}:{tripId}`（取决于 Q1）。
- 章的集合仍然由足迹**推导**；存储的只有“怎么盖的”和用户填写的信息。行程删除后，对应章变成孤儿：保留在原页显示为“已删除行程”，还是移除，见 Q3。

### 7.2 模块
| 文件 | 内容 |
|---|---|
| `data/footprint.ts` | 跨行程的国家访问记录（从 world-model 抽取，Map 与护照共用） |
| `data/passport.ts` | 国家章推导、分页、空位分配（纯函数，可测） |
| `data/stores/passport-store.ts` · `visa-store.ts` | 订阅与写入 |
| `data/card-postmarks.ts` | 卡片到达/离开章推导（替代 Itinerary 里的 `legStamp`） |
| `core/paper/stamp.ts` | 拆为外框 / 文案模板 / 图标 / 墨迹参数；`renderStamp` 对外 API 保持不变；新增 `renderPostmark` |
| `core/paper/stamp-icons.ts` | 国家地标图标注册表 |
| `views/passport/` | `passport.ts`（路由视图）· `book.ts` · `flip.ts` · `press.ts` · `bio-page.ts` · `visa-page.ts` · `stamp-back.ts` · `sound.ts` |

i18n 中英双语；Firestore rules 新增 3 个路径；按模块拆分以满足 eslint max-lines。

### 7.3 iOS
web 先行。P7.7 输出 `docs/PASSPORT_iOS_契约.md`（存储 schema、stampId 规则、推导规则、卡片邮戳规则、隐私规则），iOS 之后按契约实现。

## 9. 风险
- 桌面端鼠标“按住盖章”的手感较弱 → 需要更强的视觉反馈（印面压缩、墨圈扩散）。
- 证件信息属于敏感数据：只能是可选项，打码显示，严格排除在所有分享、导出和 AI 请求之外。
- Safari 下 3D 变换叠加 SVG 滤镜的性能需要实测。
- 国家地标手绘：已去过的国家先画，其余兜底，之后随新足迹逐步补。
