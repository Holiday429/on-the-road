# Dashboard v2 · 从看板变成操作中心

> 产品方案 + 执行计划。2026-10-11 定稿,owner 已逐条确认。
> **状态:阶段 1–6 已全部执行。** 与本方案不一致之处(以实际为准,见 `dashboard-revamp-handoff.md` 第 2 节):第三、四行改为「地图在左跨两行,花费叠在 Journal 上」;交通抽屉没有「打开预订」;横幅不再显示行程名(手机端保留一个小的切换按钮)。
> 前置阅读:`docs/dashboard-revamp-handoff.md`(仓库约定、git 流程、已有文件地图)。

## 核心原则

1. **压缩每个组件的占地**,详情一律放进**右侧抽屉**,不跳页、不堆在卡片里。
2. **横幅只放"这一段城市"的固定信息**(住宿、大交通),不放当天的参观/吃饭细节 —— 那些属于日历组件。
3. 每个组件右上角有一个**快捷操作**(`+` / `±`),Dashboard 是干活的地方,不只是看的地方。
4. **布局不随旅程阶段变化**,只有内容变(延续既有决策,见 handoff 文档)。

## 二、横幅

一行五块,**高度维持现状**。住宿和交通上下叠成一列。

| 位置 | 内容 |
|---|---|
| 最左 | 天气(**保持现状不动**) |
| 左二 | 进度表盘 + 国旗国家名 + `Day 37/74 · 第 7 站`(表盘与国家合并为一个元素) |
| 中间 | 上:**今晚住的住宿** `名称 · Aug 12–16 · 4 晚 ›`<br>下:**下一班要坐的交通** `✈️ Rome → Zurich · 2 天 4 小时后 ›` |
| 右二 | 两个迷你表盘(约 44px):当前城市、家。下方标时差 `+6h` |
| 最右 | 动态小人 logo(**保持现状不动**) |

**行为**
- 住宿 / 交通整块可点 → 右侧抽屉滑入详情。
- 抽屉里有「打开预订 ↗」:用 `window.open` 开一个约 480×720 的小窗(Airbnb/Booking 禁止 iframe 嵌入,只能这样)。
- 住宿以**当前这一段城市**为单位,不是"某一天"。一段里有多个住宿时,横幅显示今晚那个,抽屉里列全部。
- 交通默认显示**下一班要坐的**;换城市当天显示今天这班;来程在抽屉里可见。

**三种时期(布局不变,只换内容)**

| 时期 | 表盘 | 中间 |
|---|---|---|
| 出发前 | `D-12` | 第一班交通 + 第一个住宿 |
| 旅程中 | `Day 37/74` | 当前住宿 + 下一班交通 |
| 结束后 | 满环 ✓ | 一行总结:`74 天 · 9 国 · 16 站` |

**删除**:横幅现有的 `renderRateLine()`(汇率已在花费组件内)、阶段文案行、`dash.hero.*` 里不再使用的 key。

## 三、通用右侧抽屉

全页唯一的「看详情」方式。新建 `src/core/drawer.ts` + `drawer.css`。

- 从右往左滑入,宽约 420px;窄屏变成底部上滑的半屏。
- 点遮罩 / Esc 关闭;同时只开一个;焦点锁在抽屉内,关闭后焦点归还触发元素。
- 尊重 `prefers-reduced-motion`(无动画直接显示)。

**各处调用**

| 点击 | 抽屉内容 |
|---|---|
| 横幅住宿 | 这一段全部住宿:地址、入住/退房、平台、电话、确认状态、「打开预订 ↗」 |
| 横幅交通 | 班次、起降地/时间、时长、订单号、行李限额、价格、「打开预订 ↗」 |
| 日历行程项 | 备注、时长、预计花费、城市、「地图 ↗」、「记一笔」 |
| 花费总额 | 最近流水列表 |
| 行李 | 最近「买了/丢了」清单 + 快捷加减 |
| 地图上的点 | 对应的行程项 / 住宿 |

## 四、各组件

### 日历 (6 栏)
- 沿用 owner 认可的版本:左完整月历 + 右今天/明天日程。
- **落实上一轮三点反馈**:① 垂直高度回到改版前;② 月历比改版前略宽,但不必与右侧等宽;③ `‹ 10月 2026 ›` 三者紧挨居中,不与下方日历左右对齐(避免误触)。
- 行程项点击 → 抽屉(目前是跳行程页)。
- 右上角 `+`:给**选中的那天**加行程项。

### To-do (3 栏)
- 顶部小进度环(如 `3/5`),下方列表 4–5 条。
- 选中某天时,该天到期的排前面。
- 右上角 `+`。

### 行李 (3 栏)
- **去掉「临近飞行才显示」的条件,永远显示**(当前 `packVisible()` 导致旅程结束后彻底消失,用户找不到)。
- 临近飞行(≤2 天且有限额):重量 + 限额进度条 + 「还剩 X kg」。
- 平时:总重 + 件数 + 最近变化。
- 无清单:「去 Prepare 建一个清单」。
- 右上角 `+ 买了` / `− 丢了`。

### 地图 (4 栏,最左)
两种模式,切换器在卡片头部。

- **「这一天」(默认)**:跟随日历选中的日期,标出当天的行程项与住宿,按顺序连线。
- **「整个旅程」**:现有路线图(国家各自配色 + 序号圆圈,圆圈颜色表示过去/当前/未来)。
- 旅程结束后默认切到「整个旅程」。
- 按规模自适应:多国 → 区域;单国多城 → 国家;单城 → 街道级。
- 住宿只有地址没有经纬度 → 用现有地理编码补齐并缓存。
- 点地图上的点 → 抽屉。

### 花费 (4 栏)
- 总额 + 今天 + 预算进度条(现状)。
- 汇率行 + 下拉换算器(已完成,保留)。
- **记账表单压缩成一行**:金额 + 类别 + ✓;备注/日期等进抽屉。
- 总额可点 → 抽屉看最近流水。

### Journal (4 栏)
- 三张**方形**城市缩略图,左下角城市名 + 篇数。
- 点一张 → 该城市照片网格(抽屉内)。
- 城市 > 3 个时第三张右下角 `+N`。
- 「记一笔」按钮缩短为常规宽度,不再撑满。

### Where to go (12 栏,最底)
- 顶部标签:全部 / 景点 / 美食 / 咖啡 / **办公**。
- 下方横向滚动卡片;卡片 `+` 把地点加到**选中的那天**。
- **本次旅程所有城市都无推荐数据 → 整块不渲染**,上方板块底部齐平。
- **合并并删除**独立的 Nomad(办公地点)全宽条,成为这里的一个标签。

## 六、已定决策(不要重开讨论)

- 进度表盘与国家合并为一个元素。
- 横幅交通 = 下一班要坐的,带倒计时。
- 「家的时区」存个人资料,缺省按旅程出发城市推断(哈尔滨 → 北京时间)。不能用浏览器时区(旅行时会变)。
- 全页详情统一走侧边抽屉。
- 花费记账表单压成一行。
- Nomad 并入 Where to go 标签。
- 天气块、动态小人 logo 保持现状不动。
