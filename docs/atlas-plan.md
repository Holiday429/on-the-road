# P8 · 地球仪足迹（Atlas）与路线图重构 — 方案

> 2026-10-13 · 只覆盖网页版。**本文只是规划，没有改任何代码。**
> 依据：owner 对现有 World 椭圆图的反馈（截图 1）、Marginalia 地图页（截图 2）、P5 地图（`views/map/`，已在 main）、P7 护照（`feat/p7-passport`，**尚未合并**，本方案以它为前提）。
> 推翻的旧决定：P5 规划 §9 写过「3D 球体 owner 明确不要」。owner 现在要立体拟物的地球，以本文为准。

---

## 0. 一页结论

1. **两张地图，两种时间。**
   - **路线图（Route）**＝一次旅行：平面、纸质、按天推进，属于行程。保留现有路线页，改成全宽，不再和全局足迹挤在一个框架里。
   - **地球仪（Atlas）**＝一辈子的足迹：立体拟物的地球仪，跨行程累积，属于“我”，和护照同级。
2. **护照和地球仪是同一份足迹的两种呈现。** 护照记录“盖过的章”，地球仪记录“走过的地方”。两者用同一套国家判定（`data/footprint.ts`），同一套国家墨色（`country-ink.ts`），同一张国家回忆卡（P7.5 的章背面卡）。
3. **国家按“护照墨色”上色。** 去过的国家涂成那枚护照章的墨色，去得越多墨越深；没去过的是旧纸色；计划中的是铅笔虚线。地球仪看起来就像一张被你的章一点点“印满”的地球。
4. **全屏、沉浸，像 Marginalia 那样占满页面。** 但场景是“旅行者的书桌”：地球仪立在护照所在的同一张桌上，桌角躺着护照，点护照就进护照本；护照页的桌角也放着这个地球仪，点它就转到地球仪。两个页面像同一张桌子的两个视角。
5. **技术上推荐“amCharts 正射投影 + 拟物外壳”**：真正的球面投影（可上下左右转动），复用 P5 的全部数据与交互代码，再用 CSS/SVG 画出黄铜子午环、木底座、明暗和高光。three.js 真 3D 只作为可选的装饰和进场动画。
6. **把“仪式”还给护照。** P5.4 的“地图到达仪式”撤掉（它和护照的亲手盖章重复，而且用的是 P7 已淘汰的 `otr:stampsSeen`）。地球仪上只标出“到了但还没盖章”的国家，点一下就去护照盖。

## 1. 现在为什么不好看

| 问题 | 原因 |
|---|---|
| 椭圆图在框里显得小、空 | World 和 Route 共用“左图右栏 + 卡片边框”的版式，椭圆投影宽高比约 2:1，被塞进 560px 高的框，上下大片留白（截图 1） |
| 颜色几乎看不见 | 只有去过的国家着色，而且是很浅的琥珀色阶；在世界尺度下欧洲的几个国家只有几个像素 |
| 没有“物件感” | 纯数据图，和护照、票据、邮戳这套拟物语言脱节 |
| 两种用途混在一页 | 一次旅行的路线（按天、按城市）和一辈子的足迹（按国家、按年份）需要完全不同的尺度、密度和节奏 |
| 两个仪式打架 | 地图在打开时自动“转到新国家并盖章”，护照又有亲手盖章；同一个事件两处提醒 |

Marginalia 好看的原因：全屏、深底、每个国家都有颜色（色块本身就是画面），没有边框和侧栏抢视线。可以借这三点，但颜色要有旅行的含义，不是随机色。

## 2. 概念：旅行者的书桌

```
                    ┌──────────── 旅行者的书桌（同一套桌面纹理） ────────────┐
                    │                                                      │
   一辈子 ───────▶  │   🌍 地球仪 Atlas            📘 护照 Passport           │
   （我，跨行程）    │   走过的地方                  盖过的章                  │
                    │   国家涂成章的墨色            每次行程每国一枚章          │
                    │        ▲  国家回忆卡（同一张） ▲                         │
                    └────────┼──────────────────────┼──────────────────────┘
                             │ 点一趟旅行的弧线       │ 章背面「打开这次行程」
                             ▼                      ▼
   一次旅行 ──────▶  🗺️ 路线图 Route（平面纸质地图，按天推进，属于这次行程）
                             ▲
                             │  Itinerary「在地图上看」· Dashboard 行程地图 · Wrap 路线草图
```

- **地球仪**：立体、可以拿在手里转的物件；累积；不随当前行程变化。
- **路线图**：平铺在桌上的纸质地图；只画这一趟；跟着日期走。
- **护照**：已在 P7 做成全屏、桌面背景、可翻页的本子。地球仪沿用同一张桌面，形成一组“随身物件”。

## 4. 地球仪（Atlas）

### 4.1 版面（全屏）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ My Atlas · 我的地球                [足迹] [行程] [年份]          🔇  ✕   │  ← 顶部浮层，半透明
│ 17 国 · 6 大洲 · 48 城 · 212 晚 · 9 次旅行                                │  ← 一行统计，等宽字
│                                                                          │
│                         ╭──────────────╮                                  │
│                    ╭───╯   (地球仪)      ╰───╮      ┌───────────────┐      │
│                    │    子午环 + 高光 + 阴影  │      │ 国家回忆卡     │      │  ← 选中国家时
│                    ╰───╮                ╭───╯      │ （章背面卡）   │      │     从右侧滑入
│                         ╰──────┬───────╯           └───────────────┘      │
│                            ═══ 木底座 ═══                                  │
│  📘 桌角的护照                                                             │
│ ──────────────────────────────────────────────────────────────────────── │
│ 2019 ─●── 2021 ──●──●── 2023 ────●── 2025 ──●●── 2026 ▶                  │  ← 年份丝带（时间轴）
└──────────────────────────────────────────────────────────────────────────┘
```

- 地球直径 = 视口短边的约 72%，居中；底座在下，子午环斜 23.5°（地轴倾角，纯装饰）。
- 顶部、底部都是浮在场景上的半透明条，不占版面。
- 没有侧栏。国家回忆卡、图例、国家列表都是浮层，用完就收。

### 4.2 地球的样子（拟物）

| 层 | 做法 |
|---|---|
| 海洋 | 旧地图的灰青 / 深夜里的墨蓝（随主题，见 Q3），带一层很淡的纸纹 |
| 陆地（没去过） | 旧纸色，细边界线，像老地图上的国界 |
| 经纬网 | 15° 一条，像雕刻线，很淡 |
| 明暗 | 球体左上受光：径向渐变做明暗交界，右下有暗部；一道窄的高光弧（清漆反光） |
| 子午环 | 黄铜色圆环，带刻度，绕在球外；随拖动不转，只有球转 |
| 底座 | 木质底座，一个 SVG；投影落在桌面上 |
| 晨昏线（可选） | 按真实时间画出此刻的昼夜分界，夜面稍暗；“现在你在的地方是白天还是夜里”一眼可见 |

### 4.3 国家的状态与颜色（核心语义）

| 状态 | 条件（同 `footprint.ts`） | 画法 |
|---|---|---|
| 没去过 | — | 旧纸色 |
| 计划中 | 行程里有，但到达日还没到 | 同色铅笔虚线描边 + 很淡的斜线填充；不计入任何统计 |
| 到了，章还没盖 | 已到达，但 `passport-state` 里这个章是 pending | 墨色填充 + 一个轻轻跳动的空白章形小标记（“去盖章”） |
| 已盖章 | 有 placement | 该国墨色（`countryInk`，护照章的颜色）填充 |
| 去过多次 | 同一国家的行程到访次数 | 墨色加深一档，最多 3 档（1 次 / 2 次 / 3 次及以上） |
| 当前所在 | 今天在的国家 | 外圈一道细光环 + 小人站在当前城市 |

这样做的好处：
- 地球是**彩色**的（像 Marginalia），但颜色有含义：每个颜色都是你护照上那枚章的颜色。
- 去过的国家多了，地球自然变得丰富；新用户看到的是一张“等着被印满”的旧地球。
- 不需要图例也看得懂：有颜色＝去过，虚线＝要去，跳动的小章＝该盖章了。

### 4.4 镜头（顶部三个切换，像 Marginalia 的 Author Origin / Content Location）

| 镜头 | 看什么 |
|---|---|
| **足迹**（默认） | 上面这套国家墨色；城市是小墨点 |
| **行程** | 国家按“最近一次去它的行程”上色（行程封面色）；每趟旅行一条弧线（同 P5.2 规则，趟与趟不相连）；悬停一趟，其它变淡 |
| **年份** | 国家按第一次去的年份从浅到深；配合底部年份丝带，按年过滤 |

可选第四个镜头 **签证**（P7.6 已有数据）：正在有效的签证覆盖的国家/区域打一层斜纹（申根区整体），过期前 30 天变成警示色。属于“实用信息”，见 Q8。

### 4.5 交互

| 操作 | 行为 |
|---|---|
| 拖动 | 上下左右都能转（正射投影，`rotateX` + `rotateY`）；上下最多倾斜约 ±60°，避免把两极翻到正面 |
| 松手 | 惯性继续转，逐渐停（P5.4 `flingDistance` 推广到两个方向） |
| 滚轮 / 双指 | 缩放 1–6 倍；放大后地球“贴近”，子午环淡出 |
| 双击 / 双指轻点 | 以该点为中心放大一档 |
| 点国家 | 地球转到该国正面并放大（一个动画，不再切换投影）→ 回忆卡滑入 |
| 点空白 / Esc / 卡片关闭 | 回到点之前的角度和缩放（P5 已验证的“记住视角再还原”） |
| 键盘 | 方向键转动，+/- 缩放，Tab 进入国家列表，Enter 打开回忆卡 |
| 空闲自转 | 默认关（沿用 P5 设置），开着时 4 秒无操作后慢慢转 |
| 减少动态效果 | 不自转、不惯性、点国家直接跳到位 |
| 声音（可选） | 沿用护照的音效模块和静音开关：转动时很轻的轴承声，选中国家时“嗒”一声 |

**为什么不再切换投影**：P5 的国家模式要先把椭圆归零、切成 Mercator、再放大，代价是画面跳变和一整套过渡状态机。正射投影本身就能“转到正面 + 放大”，一个动画完成，状态机变成 4 个状态（见 §6.1）。

### 4.6 国家回忆卡（与护照共用）

点国家后，右侧（手机为底部半屏）滑入一张卡。它就是 P7.5 的**章背面卡**，只是从地球仪里打开：

- 正面一角是这个国家的护照章（多次到访时是一小叠，最上面是最近一次）；
- 内容：去过的城市、总晚数、每次行程（日期、城市、各自币种的花费，不跨币种合计）、日记篇数和照片；
- 动作：「在护照里看」「打开这次行程的路线」「看日记」；章还没盖时第一个按钮变成「去盖章」。

数据：`data/country-memory.ts`（已存在）。地图和护照显示的数字因此不可能不一致。

### 4.7 年份丝带（时间轴）

- 底部一条细丝带，按年份分段，每次旅行是一个点（颜色＝行程色）。
- 点一个年份：地球只显示那一年的足迹（其它国家退回旧纸色），统计行跟着变。
- ▶ 播放：从第一次旅行开始，地球随时间转到每一趟的方向，国家依次被“印上颜色”，城市点依次出现；这就是现在 World 的「回放所有旅程」，搬到这里并加上“地球跟着转”。
- 拖动丝带＝手动回放。

### 4.8 待盖章（与护照的分工）

- 地球仪**不**自动跳转、不自动播放仪式。
- 有待盖章的国家：国家上一个跳动的空白章形标记；统计行末尾一个小提示「2 枚章待盖 ›」。
- 点标记或提示 → 打开护照的托盘，进入亲手盖章；盖完返回时，地球上那个国家从“墨色 + 标记”变成正式墨色，播放一次墨迹晕开的动画（这是地球仪自己的小反馈，不是第二个仪式）。

### 4.9 下一站

- 计划中的国家用铅笔虚线（§4.3）。
- 统计行下方一行小字：「下一站 🇵🇹 葡萄牙 · 还有 12 天」，点击后地球转过去。护照不显示计划中的国家（P7 Q2），地球仪是展示计划的地方。

### 4.10 空状态与新用户

- 0 足迹：一张干净的旧地球，慢慢转一圈后停住；中间一行字「你的地球还是空白的 —— 在行程里加上第一站」+ 按钮。
- 有计划没足迹：只有虚线国家，提示「出发后，这里会被你的章一点点印满」。
- 首次打开且有历史足迹：先显示旧纸色地球，再按时间顺序快速把去过的国家依次上色（约 2 秒，可跳过），最后停在最近一次旅行的方向。只播一次（per-device 记录）。

### 4.11 手机（≤ 680px）

- 地球占满宽度，直径约 92vw，竖向居中偏上；底座缩小。
- 顶部一行：标题 + 镜头（横向可滑动的芯片）；统计行折叠成一句「17 国 · 212 晚」，点开看全部。
- 回忆卡是底部半屏，可上拉到全屏；拖动地球时自动收回半屏。
- 年份丝带在底部导航之上，可左右滑动。
- 所有点击目标 ≥ 44px；没有悬停卡片，轻点即选中。

## 5. 路线图（Route）调整

保持现有功能（路线弧、编号图钉、小人与飞机、Replay、5 个图层、导出、省份下钻），只改版式和风格：

| 改什么 | 怎么改 |
|---|---|
| 版式 | 去掉「世界 \| 路线」切换和外层框；地图全宽，右侧行程栏改为可收起的浮层（桌面默认展开，手机为底部半屏） |
| 风格 | “平铺在桌上的纸质旅行地图”：海洋淡、陆地纸色、路线是铅笔虚线、只给本次行程的国家淡淡上墨（与地球仪同一墨色） |
| 图钉 | 用 P7.0 的到达/离开邮戳语言：已到达的城市是一枚小邮戳（墨色），未来的城市是空心圆；编号保留在邮戳中心 |
| 行程切换 | 标题旁一个行程芯片，点开切换行程（复用 trip chooser） |
| 角落小地球 | 左下角传送门，见 §3.2 |
| Replay | 不变；回放到达一个新国家时，那个国家“印上墨色”，与地球仪的语言一致 |

## 6. 逻辑与数据

### 6.1 地球仪状态机（替代 P5 World 的 world → focusing → country）

```
          ┌──────── 点国家 ───────┐
          ▼                       │
 idle ──拖动──▶ dragging ──松手──▶ gliding ──停──▶ idle
  │  ▲                                              │
  │  └────────────── 关闭卡片 / Esc ─────────────┐   │
  ▼                                              │   │
 focusing ──转到并放大完成──▶ country ────────────┘   │
  ▲                                                  │
  └──────────────── 播放年份丝带 ──▶ replay ──结束/停止─┘
```
- 每次过渡一个 token，沿用 `world-state.ts` 的做法；新的点击作废旧的过渡。
- `replay` 期间禁止选国家和自转；`country` 期间禁止自转。

### 6.2 国家状态：一个纯函数

```ts
atlasCountryStates(legs, placements, today, window?) → Map<iso, {
  state: 'planned' | 'pending' | 'stamped',
  visits: number,          // 行程到访次数（Q1 规则：每次行程每国一次）
  firstYear: number,
  latestTripId: string,
}>
```
- 输入只用 `footprint.ts`（国家判定）+ `passport-state.ts`（pending / pressed）。
- `window` = 年份丝带选中的时间段；回放就是不断移动 `window.to`。
- 这个函数要和护照资料页的统计做同源测试（同 P7 `footprint.test.ts` 的做法）。

## 7. 技术方案

### 7.1 三个选项

| | A. amCharts 正射投影 + 拟物外壳（**推荐**） | B. three.js 纹理地球 | C. A 为主 + three.js 只做装饰 |
|---|---|---|---|
| 地球 | `geoOrthographic`，`panX: 'rotateX'`、`panY: 'rotateY'` | 用 d3-geo 把国家画到一张等距矩形贴图上，贴到球体 | 同 A |
| 立体感 | CSS/SVG：径向明暗、高光弧、黄铜子午环、底座、落影 | 真实光照、透视、可加凹凸 | A 的外壳 + 小地球传送门和进场飞入用 three.js（Marginalia 已有 `antique_globe.glb` 的做法） |
| 点选国家 | amCharts 原生 | 需要自己做：射线 → 经纬度 → 点在多边形内判断 | 原生 |
| 行程弧线、城市点、小人 | 复用 P5.2 | 全部重写为 3D 对象 | 复用 |
| 换主题 / 状态变化 | 原地改填色（P5.0 已有） | 每次重画整张贴图（2048px 级别，几十毫秒） | 原地改填色 |
| 体积 | 已在用（CDN + SW 缓存） | three.js 约 150KB gzip + 模型 | 装饰部分懒加载 |
| 风险 | 立体感靠“画”，需要精细调 | 工作量大、移动端性能、无障碍 | 中 |

**推荐 A，二期视效果再加 C 的装饰部分。** 理由：交互和数据都能复用 P5，状态机比现在更简单；拟物感主要来自外壳和颜色，而不是真 3D 光照。

### 7.2 模块

```
src/views/atlas/
  atlas.ts            路由视图 #atlas：场景、浮层、深链
  globe-view.ts       amCharts 正射地球：着色、转动、惯性、缩放、聚焦
  globe-skin.ts       外壳：明暗/高光/子午环/底座/晨昏线（SVG + CSS）
  atlas-state.ts      §6.1 状态机
  atlas-model.ts      §6.2 atlasCountryStates（纯函数，带测试）
  atlas-lenses.ts     三个镜头的着色规则（纯函数）
  atlas-ribbon.ts     年份丝带（基于 map-scrubber）
  atlas.css
src/views/map/        只剩路线图（map.ts 等），map-page.ts 简化
src/views/shared/desk.css   护照与地球仪共用的桌面场景 token
```

### 7.3 性能与可访问性

- amCharts 正射投影只画正面半球，约 250 个多边形，60fps 没问题；拖动时暂停高光层的重绘。
- 晨昏线每分钟更新一次。
- 国家列表浮层（可搜索）是键盘和读屏用户进入国家的等价方式。
- 减少动态效果：静态地球、无惯性、无进场上色动画。
